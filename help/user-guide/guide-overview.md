# Adobe Marketo Optimizer文档

[!DNL Adobe Marketo Optimizer]是一个人工智能优先的营销自动化解决方案，它使营销人员和业务开发代表能够规划项目、编排个性化人员历程并鉴别潜在客户。 使用对话式AI为B2B商机和客户构建并执行协调的市场和销售参与，其中提供个性化的、由AI支持的内容。
