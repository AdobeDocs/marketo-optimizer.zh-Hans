# 主页

使用[!DNL Adobe Marketo Optimizer]中的[!UICONTROL 主页]页面启动AI对话、启动技能和开放营销工作区。 在导航中选择&#x200B;**[!UICONTROL 主页]**&#x200B;以返回此页面。

个性化欢迎消息会询问您当前任务的情况。 选择如何从对话输入、意图选项、快速访问卡或技能卡开始。

观看视频，了解主页和营销工作区的导览。 以下各节提供了书面说明。

>[!VIDEO](https://video.tv.adobe.com/v/3505360/?quality=12&learn=on)

## 启动AI对话

使用[!UICONTROL 提问或开始任务]输入开始使用[!UICONTROL 同事]。 输入`/`浏览技能和命令。

1. 输入问题或描述要完成的任务。
1. 要提供支持材料，请在输入中选择&#x200B;**[!UICONTROL 附加]**&#x200B;并附加文件。
1. 在[!UICONTROL Co-worker]面板中提交提示以继续。

主页还提供了四个用于启动工作的意图选项。

| 选项 | 目标 |
| -------- | ------ |
| [!UICONTROL 计划] | 规划营销活动。 |
| [!UICONTROL 创建] | 创建营销内容或资源。 |
| [!UICONTROL 度量值] | 审查营销绩效。 |
| [!UICONTROL 优化] | 优化现有的营销活动。 |

有关详细信息，请阅读[聊天界面](/help/user-guide/agents/chat-interface.md)。

## 快速访问

选择[!UICONTROL 快速访问]卡以打开工作区或查看AI决策运行状况。

| 卡片 | 您可以访问的内容 |
| ------ | --------------------- |
| [AI决策运行状况](/help/user-guide/agents/ai-decisioning-health.md) | 故事量和按角色分类的人员百分比。 |
| [营销](/help/user-guide/marketing/marketing-management.md) | 营销工作区中的项目、人员历程和人员列表。 |
| [!UICONTROL 资源] | 电子邮件和页面的内容资产。 |
| [!UICONTROL 报告] | 绩效和参与报表。 |

## 技能

在[!UICONTROL 技能]中选择一张信息卡以开始特定的AI工作流。

| 技能 | 目标 |
| ------- | ------ |
| [!UICONTROL 创建基于角色的受众] | 使用角色信号和固定适应度生成受众。 |
| [!UICONTROL 构建全渠道计划] | 通过简短撰写跨电子邮件、Web和目标的程序。 |
| [!UICONTROL 创建超个性化电子邮件] | 草稿带有令牌和动态内容块的个性化电子邮件。 |
| [!UICONTROL 适应和基于意图的历程流量控制] | 使用帐户拟合和意图信号跨历程路由联系人。 |

您还可以浏览[!UICONTROL 同事]的代理技能。 该视频显示[!UICONTROL 使用代理技能]对话框，其中包含搜索字段和类别筛选器。 有关详细信息，请阅读[代理技能](/help/user-guide/agents/skills.md)。

## 导航到工作区

使用应用程序导航从主页或营销工作区中打开以下工作区域。

| 工作区 | 您可以访问的内容 |
| ----------- | --------------------- |
| [!UICONTROL 营销管理] | 项目、人员历程和人员列表。 |
| [!UICONTROL 历程流量控制] | [历程流量控制](/help/user-guide/marketing/journey-traffic-control.md)。 |
| [!UICONTROL 报告] | 营销绩效报表。 |
| [!UICONTROL 内容管理] | [!UICONTROL 模板]、[!UICONTROL Assets]、[!UICONTROL 片段]、[!UICONTROL Forms]、[!UICONTROL 登陆页面]和[!UICONTROL 网络研讨会]。 |
| [!UICONTROL 连接] | [目标](/help/user-guide/audiences/destinations.md)。 |
| [!UICONTROL 实验室] | [评分工作室](/help/user-guide/labs/scoring-studio.md)。 |
| [!UICONTROL 管理] | [!UICONTROL 渠道]和[!UICONTROL 项目类型]。 |

## 探索营销工作区

在导航中选择&#x200B;**[!UICONTROL 营销]**&#x200B;快速访问卡或&#x200B;**[!UICONTROL 营销管理]**&#x200B;以打开营销工作区。 使用[!UICONTROL 同事]，打开营销资源，然后返回最近访问的项目，而不返回主页。

1. 在&#x200B;**[!UICONTROL 营销]**&#x200B;面板中选择&#x200B;**[!UICONTROL 计划]**、**[!UICONTROL 人员历程]**&#x200B;或&#x200B;**[!UICONTROL 人员列表]**&#x200B;以浏览资源。
1. 选择资源以在工作区选项卡中将其打开。 或者，在&#x200B;**[!UICONTROL 最近访问的]**&#x200B;中选择一个项目。
1. 要继续使用不同的资源，请在打开的选项卡之间切换。

[!UICONTROL Co-worker]面板反映了您打开的资源。 其提示可以针对选定的项目群、人员列表或人员。 例如，打开人员记录会提供探索该人员角色和参与活动的提示。

选择&#x200B;**[!UICONTROL 折叠]**&#x200B;以隐藏[!UICONTROL Co-worker]面板，或选择&#x200B;**[!UICONTROL 交换面板]**&#x200B;以更改其位置。 有关详细信息，请阅读[营销管理](/help/user-guide/marketing/marketing-management.md)和[人员详细信息](/help/user-guide/audiences/person-details.md)。
