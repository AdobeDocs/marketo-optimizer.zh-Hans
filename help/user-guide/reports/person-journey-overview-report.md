# 人员历程概述报表

使用[!UICONTROL 人员历程概述]报告查看在选定日期范围内整个实例的活跃人员旅程数。

查看报告(_T):_

1. 在左侧导航中，选择&#x200B;**[!UICONTROL 报表]**。
1. 单击&#x200B;_列表_&#x200B;图标（![列表图标](../assets/do-not-localize/icon-table-of-contents.svg)）并在&#x200B;_[!UICONTROL 目录]_&#x200B;面板中选择&#x200B;**[!UICONTROL 人员历程概述]**。

![人员历程概述报告，显示一个平铺，其中包含活动历程数和最近30天的日期范围。](./assets/reports-person-journey-overview.png){width="700" zoomable="yes"}

您可以[更改报告的日期范围](./reports-overview.md#change-the-date-range)。

选择报表顶部的&#x200B;**[!UICONTROL 共享]**&#x200B;以下载或计划导出所有报表数据。 请参阅报告概述中的&#x200B;[_导出报告_](./reports-overview.md#export-a-report)。
